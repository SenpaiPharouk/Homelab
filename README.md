
# Cybersecurity Homelab

## Project Overview

This repository documents my journey of building a hands-on cybersecurity homelab.

The goal is to develop practical skills in cybersecurity, Linux administration, networking, vulnerability assessment, and penetration testing using virtual machines.

## Objectives

- Learn Linux system administration.
- Understand computer networking.
- Build and configure virtual machines.
- Practise network scanning and reconnaissance.
- Learn vulnerability assessment.
- Understand defensive security techniques.
- Document practical cybersecurity exercises.

## Lab Environment

| Component | Technology |
|---|---|
| Host Operating System | Ubuntu Linux |
| Virtualisation | KVM / QEMU |
| VM Management | Virt-Manager |
| Version Control | Git and GitHub |

## Project Structure

- `docs/` - Project documentation
- `virtual-machines/` - Virtual machine configurations and guides
- `practical-labs/` - Hands-on cybersecurity exercises
- `screenshots/` - Screenshots and evidence
- `scripts/` - Useful scripts
- `notes/` - Learning notes
